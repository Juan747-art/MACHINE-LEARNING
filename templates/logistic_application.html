Logistic Regression – Application

Problem description

The goal of this project is to predict whether a student is productive or not based on study habits, screen time, and lifestyle variables using a Logistic Regression model.

Dataset explanation

The dataset used is the Student Productivity & Digital Distraction Dataset from Kaggle. It contains 20,000 student records that relate study time, digital distraction, sleep habits, and lifestyle factors with productivity.

Input variables and target variable

The input variables include study hours, screen time, sleep hours, social media usage, and other lifestyle variables. The target variable represents whether the student is productive or not.

Data preparation

The dataset was cleaned by removing missing values and selecting only the most relevant features. The target variable was converted into binary values (0 and 1).

Model training process

The Logistic Regression model was trained using the scikit-learn library. The dataset was split into training data and testing data to evaluate the model performance.

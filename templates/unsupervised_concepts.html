Basic Concepts of Unsupervised Learning

Unsupervised Learning

Unsupervised learning is a type of machine learning where the model analyzes and groups data without labeled outputs. The objective is to discover hidden patterns or structures within the data.

Clustering

Clustering is a technique used to group similar data points based on their characteristics. Points in the same cluster are more similar to each other than to those in other clusters.

K-Means Algorithm

K-Means is a clustering algorithm that partitions data into K groups. It works by assigning data points to the nearest centroid and updating the centroids iteratively.

Centroids

Centroids are the center points of clusters. They are calculated as the average of all data points assigned to a cluster.

Euclidean Distance

Euclidean distance measures the straight-line distance between two points in space. It is used to determine how close a data point is to a centroid.

Iterative Process

K-Means follows an iterative process where cluster assignments and centroid positions are updated until no significant changes occur.

Variance and Convergence

Variance measures how spread out the data points are within a cluster. The algorithm aims to minimize this variance. Convergence occurs when clusters no longer change between iterations.

Linear Regression Application

This section presents the implementation of a linear regression model used to predict the NVIDIA stock closing price based on historical data.

Problem Description

The objective of this project is to predict the NVIDIA stock closing price using a linear regression model trained with historical stock data.

Dataset Explanation

The dataset contains historical NVIDIA stock prices from 1999 to 2026. Each row represents a specific day in the dataset.

Variables Used

Input Variable: Time

Output Variable: Closing Price

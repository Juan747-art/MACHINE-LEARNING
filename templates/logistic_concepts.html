Logistic Regression – Basic Concepts

What logistic regression is

Logistic regression is a supervised machine learning algorithm used for classification problems. It predicts the probability that an input belongs to a specific class.

Difference between regression and classification

Regression predicts continuous numerical values, while classification predicts categories or classes such as yes or no, true or false, 0 or 1.

Binary classification

Binary classification means the model predicts one of two possible classes. For example: spam or not spam, pass or fail, fraud or not fraud.

Target variable / class label

The target variable is the value the model is trying to predict. In logistic regression this value represents the class label, usually 0 or 1.

Features / predictors

Features are the input variables used to make predictions. These can be numerical values such as age, salary, or number of purchases.

Probability estimation

Logistic regression does not predict a number directly. Instead, it predicts a probability between 0 and 1 that the input belongs to a class.

Decision boundary

The decision boundary is the point where the model separates one class from another. It is usually based on a probability value.

Classification threshold

The classification threshold is the value used to decide the class. If the probability is greater than the threshold, the model predicts class 1. If it is lower, it predicts class 0.

Real-world use example

Logistic regression is used in fraud detection, medical diagnosis, spam filtering, and predicting whether a customer will buy a product or not.

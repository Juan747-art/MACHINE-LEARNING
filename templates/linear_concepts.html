Linear Regression Concepts

Definition

Linear regression is a supervised machine learning algorithm used to predict a continuous value based on the relationship between variables.

Variables

Independent variable (X): Time (days in the dataset)

Dependent variable (Y): NVIDIA stock closing price

Explanation with Example

In this project, linear regression is used to predict the stock price of NVIDIA based on time.

The dataset contains historical stock data, and each row represents a specific day.

The model learns the relationship between time and stock price and uses a linear equation to predict future values.

For example, if we input a specific day number, the model predicts the expected stock price for that day.

Linear Regression Concepts

Definition

Linear regression is a supervised machine learning algorithm used to predict a continuous value based on the relationship between variables.

Variables

Independent variable (X): The input data used to make predictions.

Dependent variable (Y): The output value that we want to predict.

Explanation with Example

For example, if we want to predict a student's grade based on study hours, the study hours represent the input variable (X) and the grade represents the output variable (Y).

The model learns a linear relationship between both variables and predicts the result using a straight line.

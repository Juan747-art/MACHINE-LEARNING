Linear Regression Concepts

Linear regression is a supervised machine learning algorithm used to predict a continuous value based on the relationship between variables.

Definition

Linear regression is used when the objective is to predict a numerical value. The model learns how one variable affects another using historical data.

Variables in This Project

Independent Variable (X): Time represented as days in the dataset.

Dependent Variable (Y): NVIDIA stock closing price.

Explanation with an Example

In this project, linear regression is used to predict the stock price of NVIDIA based on time. The dataset contains historical stock data, where each row represents a specific day.

The model learns the relationship between time and stock price and then creates a linear equation that can be used to predict future values.

For example, when a day number is entered, the system predicts the expected stock price for that day using the trained model.

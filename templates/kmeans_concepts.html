Unsupervised Machine Learning - Basic Concepts

What is Unsupervised Learning?

Unsupervised learning is a type of machine learning where the model works with data that has no labeled outputs. The goal is to find hidden patterns or structures within the data.

What is Clustering?

Clustering is a technique used in unsupervised learning that groups similar data points together. Points in the same group are more similar to each other than to those in other groups.

What is K-Means?

K-Means is a clustering algorithm that divides data into K groups. Each group is defined by a centroid, which represents the center of the cluster.

Centroids

A centroid is the average position of all the points in a cluster. It is recalculated in each iteration of the algorithm.

Distance Metrics (Euclidean Distance)

Euclidean distance is used to measure how far two points are from each other. It is calculated as the straight-line distance between two points in space.

Formula:

d = √((x2 - x1)² + (y2 - y1)²)

Iterative Process

K-Means works iteratively. First, centroids are initialized. Then, each data point is assigned to the nearest centroid. After that, new centroids are calculated. This process repeats until the centroids no longer change significantly.

Variance and Convergence

Variance measures how spread out the data points are within a cluster. The goal of K-Means is to minimize this variance. Convergence occurs when the centroids stop changing between iterations.

Real-World Applications

  • Customer segmentation
  • Market analysis
  • Image compression
  • Anomaly detection

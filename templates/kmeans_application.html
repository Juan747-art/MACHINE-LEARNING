Clustering Application - K-Means

Context of the Data

This dataset represents student productivity based on daily habits such as study time, sleep patterns, social media usage, and physical activity.

Dataset Explanation

  • Records: More than 1000 students
  • Features used: Study hours, sleep hours, social media usage, exercise time

Data Preprocessing

Only numerical features were selected for clustering. No missing values were considered in this implementation.

Model Training

The K-Means algorithm was used with K = 3 clusters to group students based on similar behavior patterns.

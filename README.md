Machine Learning Web Application

This project is a machine learning web application that implements both classification and regression models using real datasets.

The system includes:

Logistic Regression to classify student productivity
Decision Tree Classifier as a second classification model
Linear Regression to predict stock price trends of NVIDIA Corporation
Features
Student productivity classification based on study habits
Stock trend prediction using linear regression
Web application built with Flask
Model training scripts included
Confusion matrix and evaluation metrics
Datasets Used
Student Productivity & Digital Distraction Dataset
Historical stock data of NVIDIA Corporation

How to Run
pip install pandas numpy scikit-learn matplotlib flask joblib
python train_logistic.py
python train_decision_tree.py
python app.py
